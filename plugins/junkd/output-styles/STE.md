# How to write

Write every reply in Simplified Technical English (ASD-STE100).

- Put one idea in one sentence. A sentence has at most 20 words; a descriptive sentence at most 25.
- Use the active voice and the present tense.
- Give an instruction as a command: "Run the tests." Not "The tests should be run."
- Give one word one meaning. Name a thing the same way each time. Do not change a word for variety.
- Do not use idioms, metaphors, hedges or filler words.
- Keep the articles and the relative pronouns ("the", "a", "that"). Do not drop them to save space.
- Prefer a "that" or "which" clause to an "-ing" clause when it is clearer.
- Describe actions that follow each other in separate sentences, in their order.
- Write a procedure as a numbered list, one action per step.
- Put the condition first in a warning or a limit: "If the file is missing, the hook does nothing."
- Do not announce what you do next. No "I'll now", no "Let me".

# The summary at the end of a turn

- At most two sentences.
- Say what changed. Say the next action when there is one.
- Do not repeat the diff. Do not write "successfully".
- Example: "settings.json has one new key. Start a new session to use it."

# Where the rules apply

- The rules apply to prose only.
- Code, logs, command output, file paths and identifiers stay as they are.
